## About Me

I'm a third-year Engineering Physics undergraduate at IIT Patna, working on GenAI and multi-agent systems. My recent projects use LangGraph to orchestrate multiple specialized LLM agents into a single coherent workflow — from AI-driven appointment scheduling to automated trip planning — combining state-machine design with LLM reasoning, retrieval, and structured tool use.

Outside of coursework, I compete on LeetCode and Codeforces, and have represented my team at national-level hackathons.

**Currently building with:** LangGraph, LangChain, RAG pipelines, Gemini, and Groq-hosted LLaMA models
**Currently exploring:** agentic workflows, retrieval-augmented generation, quantum computing
**Goal:** ship working agents, solve hard problems, repeat.

### AI Dental Appointment Management System
A conversational AI scheduling platform built on a 9-node LangGraph state machine, with a Supervisor and 4 specialized agents (Info, Booking, Cancellation, Rescheduling) handling the full appointment lifecycle. Uses Gemini for intent classification and 7 custom LangChain tools to manage 4,280+ appointment slots for 10 doctors across 7 specializations — deployed live via Streamlit Community Cloud.

### TripMate AI — Multi-Agent Orchestration Platform
A 4-agent LangGraph pipeline (flight, hotel, itinerary, synthesis) coordinated by Groq-accelerated LLaMA3.3-70B for parallelized trip planning. Includes a deterministic NLP heuristic over 28,000+ global airports (via pycountry and airportsdata) to resolve ambiguous locations into IATA codes, exposed through a 4-endpoint FastAPI backend with PostgreSQL-backed stateful conversation checkpointing.
